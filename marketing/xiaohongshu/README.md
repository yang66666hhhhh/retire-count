## 发布文案

### 版本 A（情绪，适合首发）

```text
昨天加班到十点，我突然想算一笔账：
我还要上多少天班？

输入生日和退休年龄，出来一个数字：8258 天。

然后顺手把养老金也算了。
55 岁退休，社保每月大概发 11446，
但我想花 12000，
每月差 554。

554 不多，但它会跟着我 30 年。
折算到退休那天，是 15 万。

我把这个计算做成了一个小网页：
不用注册、不上传数据、断网也能用。
填 3 个数，30 秒出结果：
· 社保每月发多少
· 退休时还差多少
· 现在每月该存多少

最触动我的不是缺口，
是它把“退休”从一句口号，
变成了一个可以准备的数字。

你算出来还要上多少天班？
评论区交个数字，我挨个看。
```

### 版本 B（实用，适合第二、三篇）

```text
如果你也想知道退休后钱够不够花，
可以试试我自己做的这个小工具。

3 步：
1️⃣ 出生年月 + 性别
2️⃣ 退休年龄 + 城市
3️⃣ 月薪 + 已缴年限 + 退休后想花多少

出来 3 个数：
社保每月发 / 退休时还差 / 现在每月存

我最喜欢的是它不说术语：
“缺口现值”叫“退休时还差”，
“替代率”直接写“相当于现在工资的 46%”，
看不懂的词点 ⓘ 就有解释。

另外三点：
· 不用登录，数据只存在你手机里
· 可以加到桌面，断网也能开
· 免费，没有广告

适合：想提前算账的打工人 / 帮爸妈估算的子女
```

## 发布与互动

- 时间：工作日 19:00–22:00 或周日晚。
- 发布后 30 分钟回复每条评论，置顶一条：「算完的姐妹把天数打在评论区，我帮你看缺口大不大。」
- 正文和图片都不要放网址 / 二维码，用「搜 RetireCount」承接。
- 连发 3 篇同系列（倒计时 / 缺口 / 蓝图），别只发一篇。

## 注意

- 数字取自 2026-10-21 的演示档案。晚些发的话，封面「8,258」可以换成你当天打开页面看到的数字，正文同理。
- 图上已带「演示数据」和免责声明，别裁掉。
- 重新生成：

```bash
node scripts/make-xhs-images.mjs
```

脚本用本机 Chrome 无头截图，改文案或数字后直接重跑即可。
