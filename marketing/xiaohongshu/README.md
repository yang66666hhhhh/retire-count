## 看哪个数判断成败

创作服务平台 → 笔记数据 → **核心数据**：

- **点击率 = 阅读 ÷ 曝光**。合格 10–12%，优秀 15%+。
  低于 8% 换封面标题，不用改正文。
- **互动率 =（赞 + 藏 + 评）÷ 阅读**。冷启动要 5%+ 才会进下一级流量池。
- 发布 2 小时后阅读仍 <100 且 0 互动，这篇基本定型，直接准备下一篇。

# 承接：不发链接，怎么让人用到

先说结论：**小红书没有合规的外链入口**。

- 正文、评论、图片里放网址或二维码 → 轻则限流，重则删笔记
- 个人号开不了「蓝链」（需要企业资质和备案）
- 在小红书站内搜「RetireCount」只能搜到你的笔记，**搜不到网页**

所以别再写「搜 RetireCount 就能用」，用户会以为你在敷衍。

## 三条路，按推荐顺序

### 1. 私信承接（现在就能用）

笔记结尾：`评论区扣「退休」，我私信发你。`
置顶评论：`计算器是我自己做的，不用登录。想要的扣「退休」。`

私信第一条（不要带 `https://`，避免被系统折叠）：

```text
链接在这，复制到浏览器打开就行：
yang66666hhhhh.github.io/retire-count

填生日、退休年龄、月薪，30 秒出结果。
```

注意：

- 别群发同一句，一条条发，前面加一句对方评论里的内容
- 新号一天别超过 20–30 条私信，容易被限制
- 对方没回之前，小红书对陌生人私信有次数限制，先回评论再私信

### 2. 主页简介（长期入口）

```text
退休倒计时｜想要计算器私信「退休」
```

简介里同样不要放网址。

### 3. 公众号承接（中期，最稳）

注册一个免费订阅号，发一篇《我还要上多少天班？》，
文末「阅读原文」放网页链接——微信文章里可以放外链。

小红书这边只做内容，不放任何链接。0 粉阶段先用私信，
等有几百粉再考虑把「公众号」写进简介（这句话本身也有引流风险）。

## 不要做

- 图片里放二维码（会被识别，直接限流）
- 正文 / 评论区放链接
- 私信发可点击短链（比纯文本更容易被折叠）
- 同一篇笔记反复改（每次改都重新审核）

## 关于链接太长

`yang66666hhhhh.github.io/retire-count` 确实不好打。
以后可以迁到 Cloudflare Pages，地址会变成 `retire-count.pages.dev`，
短一半，私信里更好发；也可以买个几十块一年的短域名，转化会明显好一些。
